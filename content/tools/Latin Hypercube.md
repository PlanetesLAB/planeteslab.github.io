In the context of statistical sampling, a square grid containing sample positions is a [Latin square](https://en.wikipedia.org/wiki/Latin_square) if (and only if) there is only one sample in each row and each column. A Latin [hypercube](https://en.wikipedia.org/wiki/Hypercube) is the generalization of this concept to an arbitrary number of dimensions, whereby each sample is the only one in each axis-aligned [hyperplane](https://en.wikipedia.org/wiki/Hyperplane) containing it.
